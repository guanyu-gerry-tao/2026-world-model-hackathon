### Competition Rules

- No writing code before the hackathon begins (brainstorming and discussion allowed)
- Maximum 5 members per team
- One submission per team
- Required submissions: APK file + ~45 second demo video (showing in-headset footage, no third-party copyrighted music)
- Demo video must be publicly visible
- All paid SDKs, APIs, and design tools must be disclosed in submission
- Judging in two rounds: Round 1 checks theme compliance, Round 2 evaluates concept, technical execution, and track-specific criteria

### Available Technical Resources

**World Model generation**
- World Labs Marble API (primary tool)
- Genie (experimental environment generation)
- Ling Bot World (open-source World Model)

**XR development kits (choose one)**
- WebXR Kit: Node ≥20.19, SparkJS 2.0
- Unity Kit: Unity 6000.2.10f1
- Unreal Kit: UE 5.5 (this version only)

**Hardware**
- Organizers provide a limited number of Quest 3 (bring your own if possible)
- PICO devkit on-site support
- 40+ robots (Solo Tech, for Physical AI track)
