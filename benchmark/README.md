# Benchmark Assets

Shared standard Demo assets for the team. **All files are committed to git for everyone to sync.**

---

## Directory Structure

```
benchmark/
└── tokyo-shibuya/               # First Demo city: Tokyo Shibuya
    ├── photos/                  # Raw user photos (input)
    │   ├── photo1.jpg
    │   └── ...
    ├── template.png             # Original city panorama template (input)
    ├── panorama-banana.png      # Panorama processed by Gemini (Nano Banana Pro)
    └── world.spz                # Gaussian Splat generated by World Labs Marble
```

---

## What Each File Is

| File | Source | Purpose |
|------|------|------|
| `photos/*.jpg` | Photos taken or collected by the team | Used as pipeline input, uploaded to Gemini |
| `template.png` | 360° panorama of Shibuya street found online | City template base image for Mode A |
| `panorama-banana.png` | Gemini API output | Validates Gemini blending result; can also be sent directly to Marble |
| `world.spz` | Downloaded from Marble API | Loaded and rendered directly by the PICO WebXR frontend |

---

## How to Update

After generating a new version, overwrite the corresponding file and commit:

```bash
# Example: update the Shibuya spz
cp ~/Downloads/new-world.spz benchmark/tokyo-shibuya/world.spz
git add benchmark/tokyo-shibuya/world.spz
git commit -m "chore: update tokyo-shibuya world.spz (Marble 0.1-plus)"
```

---

## Notes

- `world.spz` files are large (50–100 MB); if `git push` fails consider using git-lfs
- `panorama-banana.png` is a 2:1 equirectangular projection; width of 4096px or more is recommended
